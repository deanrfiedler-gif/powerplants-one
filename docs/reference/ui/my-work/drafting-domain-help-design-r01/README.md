# Drafting and domain help design r01 — retained captures

These fifteen images retain the Drafting and domain help design (AI-04) that Dean accepted on 31 October 2026. They cover an email reply drafted from the messages a person ticks, a project update drafted in Stakeholder updates, and equipment help answered only from reviewed Knowledge, at desktop 1440, with the email draft at tablet 1024 and equipment help at phone 390 and 320.

Ten states are in image 15. The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/drafting-domain-help-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Image 15 is a frame holding copies of the state cards and their labels.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. Every person, record, version, time, email, article and answer is a synthetic fixture, and the steps shown are design placeholders, not validated technical instructions. These are design compositions, not application captures, and they set no UI baseline.
