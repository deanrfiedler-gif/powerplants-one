# Recurring checks design r01 — retained captures

These nineteen images retain the Recurring checks design (AI-07) that Dean accepted on 1 November 2026. They cover the checks list, template library, new check with preview, run history, run detail, partial run and paused by budget at desktop 1440, the checks list at tablet 1024, the My Work suggestion card and run detail at phone 390 and 320, and seven states.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/recurring-checks-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. Every person, record, run, time and cost is a synthetic fixture.

The main frames show runs as if PPO checks were scheduled. No scheduler exists; image 16 shows what a build displays until scheduling is decided.
