# Voice capture design r01 — retained captures

These nine images retain the voice capture design (`scope:AI-05`, Voice capture and transcript review) that Dean accepted on 31 October 2026. They cover:
- push-to-talk in the accepted AI-01 panel on desktop at 1440, and the hand-off to the AI-02 review;
- the full flow on phones at 390 and 320;
- eleven panel-width state cards, including the proposed Voice settings rows with the speech-to-text service shown as To be decided;
- a proposed later use in My jobs, which is not the pilot.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/voice-capture-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Images 06–09 are frames holding copies of several frames, 40 px apart on a grey background.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The organisations, people, references, times and provider labels are synthetic fixtures; they are not adopted operating rules.
