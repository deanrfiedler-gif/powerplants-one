# Answer evidence design r01 — retained captures

These eighteen images retain the Answer evidence design (AI-03) that Dean accepted on 31 October 2026, for the register destination `/assistant/evidence` and the evidence drawer in the assistant panel. They cover source chips on an answer, the evidence drawer, the full evidence view, missing and conflicting evidence, and the stale, access-changed and untrusted-instruction cases at desktop 1440; the full view at tablet 1024; and the answer, the evidence sheet and missing evidence at phone 390 and 320.

Six states are included in image 16. Images 17 and 18 show the two frames of the accepted Assistant AI-01 design as this decision changed them; AI-01's own [r01 captures](../assistant-design-r01/README.md) stay as accepted on 24 October 2026. The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/answer-evidence-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Image 16 is a frame holding copies of the six state cards. Frames that show a long page or answer at 960 px simulate scrolling.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. Every person, record, version, time and answer is a synthetic fixture. These are design compositions, not application captures, and they set no UI baseline.
