# Site readiness design r01 — retained captures

These twenty-three images retain the Site readiness design (FI-05, site induction, risk and biosecurity review) that Dean accepted on 31 October 2026. `/my-jobs/site-readiness` is built to an earlier layout; this design is not built. They cover:
- the coordinator review across upcoming visits, one technician's readiness and a requirement's detail at desktop 1440;
- the technician view at tablet 1024;
- six technician screens at phone 390 and at 320: the readiness list, requirement detail with Acknowledge, biosecurity rules, changed since acknowledged, all acknowledged with one condition open, and offline;
- seven phone states.

The decisions, conformance declaration and departures D1–D12 are in [the design decision](../../../../decisions/site-readiness-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own, from the [logo pack r01](../../ppo-logo-pack/README.md). The people, sites, visits, requirements, source texts, revisions and acknowledgements are synthetic fixtures. No rule shown is a Hillview Growers, Powerplants or regulatory rule. The images are design compositions, not captures of the application, and set no UI baseline.
