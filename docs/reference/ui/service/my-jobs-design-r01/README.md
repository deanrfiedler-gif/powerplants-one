# My jobs design r01 — retained captures

These thirty-nine images retain the My jobs design (FI-01, with the FI-02 offline copy) that Dean accepted on 15 October 2026. The design covers the technician list `/my-jobs` and the visit page `/my-jobs/[id]`, phone first, with desktop and tablet and the remaining r05 timer states. The decisions, conformance declaration, display rules and departures are in [the design decision](../../../../decisions/my-jobs-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. Visits, work orders, people, sites, times, readings and photos are synthetic fixtures. The images are design compositions, not captures of the application. The built My Jobs page keeps the r05 timer baseline until a build implements this design.
