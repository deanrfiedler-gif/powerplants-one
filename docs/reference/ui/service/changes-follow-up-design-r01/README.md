# Changes and follow-up design r01 — retained captures

These twelve images retain the Changes and follow-up design (PL-04) that Dean accepted on 18 October 2026. They cover two routes:
- `/schedule/changes`: the queues at desktop 1440 × 900, tablet 1024, and phone 390 and 320, with the selected visit, a stale request, an exact appointment from Travel review, customer follow-up and an accepted move;
- `/schedule/policy-impact`: Policy impact at desktop 1440 × 900, drawn in the same workspace.

Four phone states are included. The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/changes-follow-up-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Image 12 is a frame holding copies of the four state frames side by side on the canvas grey.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The visits, people, growers, sites, versions and times are synthetic fixtures. The images are design compositions, not captures of the application.
