# Capacity review design r01 — retained captures

These eighteen images retain the Capacity review design (`scope:PL-03`, Cross-domain resource demand and capacity, `/schedule/capacity`) that Dean accepted on 30 October 2026. They cover the capacity grid by week and by day, the cell detail popover, the Demand list, the Skill view, analysis-only exclusions, the tablet layout, the phone layouts at 390 and 320, and seven states.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/capacity-review-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The people, hours, skills, records and references are synthetic fixtures; they are not adopted operating rules and grant no authority. The images are design compositions, not captures of the application.

- All prototype reactions were removed. No copied flow starting point was added to the Captures page.
