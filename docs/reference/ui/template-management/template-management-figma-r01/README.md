# Template management design r01 — retained captures

These twenty images retain the Template management design (DK-06, app label "Templates") that Dean accepted on 15 October 2026. The decisions, conformance declaration, display rules and departures are in [the design decision](../../../../decisions/template-management-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size; the states board is a Figma section, which exports with a 40 px margin. Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. Template identities, hashes, byte counts, proposals, people, company, sites and dates are synthetic fixtures; the dependency paths name real repository files and their sizes and hash prefixes at `41c8479`. The images are design compositions, not captures of the application, which has no template page; `/documents/templates` is unbuilt.
