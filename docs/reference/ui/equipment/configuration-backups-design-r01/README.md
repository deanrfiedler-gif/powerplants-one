# Configuration backups design r01 — retained captures

These nineteen images retain the Configuration backups design (EQ-08) that Dean accepted on 31 October 2026. `/equipment/backups` is built on an earlier single-column layout; this design restyles it, and that build is not decided. They cover:
- the backup register, grouped by status, and the gaps worklist;
- an asset's backup history with its evidence stages, and a backup out of date after a configuration change;
- the Record backup and Record restore evidence side forms;
- tablet 1024, the technician's history and form at phone 390 and 320, and eight states.

The decisions, conformance declaration and rules D1–D10 are in [the design decision](../../../../decisions/configuration-backups-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size, from copies `2836:380661`–`2836:394264` on Captures at y = 630,000.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own, from the [logo pack r01](../../ppo-logo-pack/README.md). The people, organisations, sites, assets, backups, checksums and storage paths are synthetic fixtures and grant no access. The images are design compositions, not captures of the application.
