# Catalogue import design r01 — retained captures

These twenty-seven images retain the Catalogue import design (PD-05) that Dean accepted on 31 October 2026. `/products/import` is built, but has not moved to this design. They cover nine desktop frames, tablet 1024, five phone frames at 390 and 320, and twelve states.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/catalogue-import-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. The story is synthetic, and its supplier, hashes and proposed IDs are fictional.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own, from the [logo pack r01](../../ppo-logo-pack/README.md).
