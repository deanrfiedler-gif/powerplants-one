# Product compatibility design r01 — retained captures

These twenty images retain the Product compatibility design (PD-04) that Dean accepted on 1 November 2026. `/products/compatibility` is built, but has not moved to this design. They cover seven desktop frames, tablet 1024, four phone frames at 390 and 320, and eight states.

The decisions, conformance declaration and departures D1–D14 are in [the design decision](../../../../decisions/product-compatibility-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. The story is synthetic.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own, from the [logo pack r01](../../ppo-logo-pack/README.md).
