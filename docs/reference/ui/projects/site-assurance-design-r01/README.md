# Site assurance design r01 — retained captures

These twenty-three images retain the Site assurance design (`scope:PJ-09/site-assurance`) that Dean accepted on 1 November 2026. No application page exists at the proposed `/projects/assurance`. They cover:
- the overview, grouped by release state;
- the ITP record at full length, a blocking hold point, witness invitation and attendance, a failed check with its defect and retest, a draft plan revision, a release with exclusions, the handover to PJ-09 and Run a check;
- tablet 1024, phone 390 and 320 for the site supervisor, and seven state cards.

The decisions, conformance declaration and D1–D12 are in [the design decision](../../../../decisions/site-assurance-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own, from the [logo pack r01](../../ppo-logo-pack/README.md).
