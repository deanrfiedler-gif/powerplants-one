# Project initiation design r01 — retained captures

These forty-one images retain the Project initiation design (PJ-01, project initiation and receiving review) that Dean accepted on 31 October 2026. `/projects/new` is built in part; this design is not built. They cover:
- sixteen desktop 1440 frames, from the worklist through review, create, link, return and start;
- the receiving review at tablet 1024;
- the review summary, raising a question and answering one at phone 390 and at 320;
- seventeen states;
- the My Work amendment frame. The Project record header amendment is capture 10.

The decisions, conformance declaration and departures D1–D15 are in [the design decision](../../../../decisions/project-initiation-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own, from the [logo pack r01](../../ppo-logo-pack/README.md). The people, sites, projects, dates, questions, limits and project class are synthetic fixtures. No rule shown is a Woodhaven, Powerplants or operating rule. The images are design compositions, not captures of the application, and set no UI baseline.
