# Stakeholder updates design r01 — retained captures

These nineteen images retain the Stakeholder updates design (PJ-08) that Dean accepted on 19 October 2026. They cover the proposed `/projects/updates` register and update record: the register, the draft and its Sources view, Prepare to send, the approver's review, Approve and send, Return for changes, the sent update, Correct a sent update, a held update, Update settings and the project record's Updates view on desktop 1440; the register on tablet 1024; the list at 390 and 320, the review and the Approve and send sheet on phone; and nine states.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/stakeholder-updates-figma-design.md). The phone frames use the compact phone header of the Phone header amendment (`docs/decisions/phone-header-amendment.md`, draft PR #606). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Captures 02, 06, 09 and 17 are full length; the prototype uses 900 px and 844 px scrolling copies of them.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The people, organisations, projects, addresses and dates are synthetic fixtures. The images are design compositions, not captures of the application.
