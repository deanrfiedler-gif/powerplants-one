# Deals design r03 — retained capture

This image retains the Deals Filters frame after the [31 October 2026 amendment](../../../../decisions/deals-figma-design.md#amendment--31-october-2026), which adds the Expected close range. It is the only frame that changed, so the other 27 captures in [r02](../deals-design-r02/README.md) still show the current design. All r02 bytes stay unchanged. Retain these bytes unchanged; a revised design receives a new revision folder.

The image is one Figma frame exported at scale 1 at its exact frame size. Every icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The deals and organisations are synthetic fixtures; they are not adopted operating rules and grant no authority. The image is a design composition, not a capture of the application.
