# Deal record page design r01 — retained captures

These thirteen images retain the deal record page that Dean accepted on 16 October 2026, the fourth record type on the shared record layout. The decisions, the Pipedrive observation, the conformance declaration, display rules, departures and open questions are in [the design decision](../../../../decisions/deal-record-page-design.md). Retain these bytes unchanged. A revised design receives a new revision folder.

Each image is one Figma frame, exported at scale 1 at its exact frame size. Images 09 to 13 are board frames: each holds copies of several accepted frames, laid out with a label above each one. Before export, every Font Awesome icon was replaced by a plain placeholder square, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The check marks in the stage bar and the readiness bar are icons, so they appear as squares too. The Powerplants logo is the company's own. Figures, names, references and dates are synthetic fixtures. The images are design compositions, not captures of the application, which still shows the deal as a page header over eight tabs.
