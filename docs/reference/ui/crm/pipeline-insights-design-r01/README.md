# Pipeline insights design r01 — retained captures

These eighteen images retain the Pipeline insights and forecast review design (`scope:CR-04`) that Dean accepted on 31 October 2026. They cover:
- the overview, stage ageing, next actions, close-date movement, forecast review, statement form, definitions, drill-through, snapshot, review lifecycle and filters, on desktop at 1440;
- the overview on tablet at 1024;
- the overview cards and the no-next-action list on phones at 390 and 320;
- twelve states.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/pipeline-insights-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Images 15–18 are frames holding copies of several frames, 40 px apart on a grey background.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The customers, people, deals, statements and dates are synthetic.
