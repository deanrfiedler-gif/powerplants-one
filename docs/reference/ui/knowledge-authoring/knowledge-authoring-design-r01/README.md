# Knowledge authoring design r01 — retained captures

These twenty-one images retain the Knowledge authoring, review and learning intake design (DK-05) that Dean accepted on 30 October 2026. `/knowledge/review` is not built; the design defines the build. They cover the worklist, triage from Findings, the article editor, the reader preview, technical review with comments, validating a hypothesis, publish and withdraw, the tablet editor, phone capture and approval at 390 and 320, and eight states.

The decisions, conformance declaration and departures D1–D12 are in [the design decision](../../../../decisions/knowledge-authoring-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size, from copies on the Captures page (115:2) from y = 480,000. The story is synthetic: no step, value or safety note shown is a real or validated technical or safety procedure.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository.
