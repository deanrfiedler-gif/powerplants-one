# Onboarding & support design r01 — retained captures

These twenty-five images retain the User onboarding, learning and support design (AD-10) that Dean accepted on 1 November 2026. `/help/onboarding` is not built. They cover ten desktop frames, tablet 1024, six phone frames at 390 and 320, and eight states.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/onboarding-support-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. The story is synthetic, and its people, requests, releases and counts are fictional. Capture 08 shows KPI-15 with an approved definition so that the layout can be judged: that approval is story only, and capture 22 shows today's true state.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own, from the [logo pack r01](../../ppo-logo-pack/README.md).
