# Reference cases and calibration proposals design r02 — rail amendment captures

These twelve images show the shared Estimating rail that Dean chose: Reference cases after Cost sources and Outcomes after Reviews & approvals. Ten are ES-10 frames with a rail, and two show the same rail on ES-09.

Only the rail differs from the accepted [ES-10 r01 captures](../reference-calibration-design-r01/README.md), which stay unchanged. The r01 phone and states images (11–15) still apply, because those frames have no rail. The decision is the [estimating navigation amendment](../../../../decisions/estimating-navigation-amendment.md), recorded in section 7 of the [ES-10 design decision](../../../../decisions/reference-calibration-figma-design.md).

Each image is one Figma frame exported at scale 1 at its exact frame size. Every value is synthetic. Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so the new folder icon cannot be told apart from the others in these images. The Powerplants logo is the company's own.
