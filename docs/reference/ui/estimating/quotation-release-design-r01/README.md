# Quotation release design r01 — retained captures

These 26 images retain the Quotation release design (`/estimating/quotes/[id]/release`, ES-05) that Dean accepted on 30 October 2026, at desktop 1440, tablet 1024 and phone 390 and 320. They cover the overview, preparation with appendices, the exact output preview, approval by a separate named approver, the preparer blocked, a return with a reason, the issue recheck and register, the Send composer, the send outcomes, the source-change hold, revisions and six states.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/quotation-release-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Frames marked full length are taller than the 1440 × 900 viewport. Phone frames are the 844 px first screen, so content below it is clipped.

Every Font Awesome icon (743 in all) was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The people, addresses (`*.example`), organisations, references, hashes and amounts are synthetic.
