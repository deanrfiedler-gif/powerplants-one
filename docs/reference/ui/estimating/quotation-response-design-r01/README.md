# Quotation response design r01 — retained captures

These 22 images retain the quotation response design (`/estimating/quotes/[id]/response`, ES-06, Figma page "Customer response · ES-06") that Dean accepted on 30 October 2026: the staff record of the customer's answer, any negotiation and preparation for conversion, at desktop 1440, tablet 1024 and phone 390 and 320.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/quotation-response-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Frames are full length, so most are taller than the 1440 × 900 viewport.

Every Font Awesome icon (623 in all) was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The people, addresses, organisations, quotations, values, response IDs and dates are synthetic fixtures. The images are design compositions, not application captures or UI baselines, and they accept nothing about the running page.
