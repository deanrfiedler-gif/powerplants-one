## How to use these captures

- **Visual authority.** For layout, hierarchy, components, wording and the set of states, the captures are the target.
- **Native rules win on values and behaviour.** Calculated values come only from the engine, severities and states from ADR-0038, and import behaviour from ADR-0044. Where a capture disagrees, build the native rule and record the difference as a departure.
- **Like-for-like data.** [`tests/helpers/fertigation-board-scope.ts`](../../../../../tests/helpers/fertigation-board-scope.ts) builds the board's scope: r02's synthetic sample, imported with the proposed placements and completed with the declarations the board shows as made. FN-T117 pins the figures it reproduces: 44 m³/h connected, a 28 m³/h peak, 3.0 ha, 11,000 containers, 33 m³ a day, 39.4 m required against 45.4 m on the curve, supply at 156% relying on storage, the filter at 80%, pump head at 87% and Channel A at 112%. Compare application captures made with this scope at the same widths.

## Capture method and limits

Captured on 24 September 2026 in headless Chromium through Playwright, at device scale 1. The Design runtime was not used:

- **Static artboards.** Every artboard's markup is static except the shared section rail, whose nine template values were filled exactly as its own script computes them; the standalone rail uses its default active section, Overview.
- **Shared parts.** The shared header and rail were inlined where each artboard imports them.
- **Checks.** No page reported an error, and no template value or import was left unresolved.
- **Fonts.** Roboto was served from `public/brand/Roboto-variable.ttf`. Verdana is not installed on the capture machine, so the two report pages use their stated fallback, DejaVu Sans, and their text metrics differ slightly from a machine with Verdana.
- **Board 10.** Its content runs 12 px past its declared 2,660 px. It is captured at its full content height of 2,671 px rather than clipped.
