# Estimate review design r01 — retained captures

These 20 images retain the Estimate review design (`/estimating/estimates/[id]/review`, ES-04) that Dean accepted on 30 October 2026, at desktop 1440, tablet 1024 and phone 390 and 320. They cover the review overview, the three review kinds, the owner's resubmission, a kept decision, pricing exceptions, self-review refused, the handover to ES-05, history and five states.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/estimate-review-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Desktop frames are full length. Phone frames are the 844 px viewport, so their content continues below the sticky action bar.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The people, organisations, references, values, dates and fingerprints are synthetic. These are design compositions, not application captures, and no outcome shown is a production claim.
