# Priva Fertigation Workbench Figma design r01 — retained captures

These fourteen images retain the Figma design of the Priva fertigation record workspace (`/estimating/fertigation/[id]`) that Dean accepted on 12 October 2026. The design moves the page built from the design board onto the accepted Figma conventions: the Shell v2 rail and flush secondary menu, the shared record layout and the shared register grid. The decisions, the conformance declaration, the display rules and the differences the application should adopt are in [the design decision](../../../../decisions/fertigation-figma-design.md). Retain these bytes unchanged. A revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1. Images 01–09 are the nine views at 1440 px wide, drawn at full length: in the design each view is a 1440 × 1000 frame whose content scrolls, and the capture copy was lengthened to its content so the whole view is retained. Images 10–12 are the Overview frame at 1440 × 1000 with one overlay open. Image 13 is a board holding three phone frames at 390 × 844 with a label above each. Image 14 is the twelve-state sheet.

Before export, every Font Awesome icon was replaced by a plain placeholder square, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. Severity marks, the leaf beside the site and the chevrons therefore appear as squares; the words beside them carry the meaning. The Powerplants logo is the company's own. Every figure is from the synthetic board reference scope (`tests/helpers/fertigation-board-scope.ts`, FN-T117) and the engine `PPO-FERT-NATIVE-CALC-r01`; names, references and dates are synthetic. The images are design compositions, not captures of the application. The built page and its own captures are in [the board parity evidence](../../../../testing/evidence/fertigation-board-parity/README.md).
