# ES-02 Estimation Wizard design board r01 — retained captures

These thirty images retain the in-app ES-02 Estimation Wizard design board produced in the 23–24 September 2026 design session. The board re-bases the wizard onto the running application shell, [build plan r04](../PPO-ES-02-Estimation-Wizard-Discovery-Alternatives-and-Revisions-Refinement-Build-Plan-r04.md) and the runtime tokens. It carries one user decision (six equipment families) and a set of proposals that are **not** accepted. The decision, proposals and build findings are in [the design board record](../../../../decisions/es02-design-board.md). Retain these bytes unchanged; a revised board receives a new revision folder.

Each image is one artboard captured at its exact board size in CSS pixels, at device scale 1. Figures, names and references in them are synthetic fixtures (the Northbank scenario of build plan r04 §4.9). Board 04 embeds three captures of the running application; those captures are retained separately as [evidence](../../../../testing/evidence/es02-design-board-r01/README.md).

## Images

Numbered boards (01–10) explain the package. S0–S5 are the Discovery steps, V1–V6 the workspace views and panels, X1–X4 drawn states and R1–R4 the responsive compositions. Board 08 catalogues all 24 states; four are drawn full size.

## Capture method and limits

Captured on 24 September 2026 in headless Chromium 141.0.7390.37 through Playwright 1.56.1. The artboards are static HTML: each page was loaded from a local copy identical to the published file except that the logo and the three board-04 application captures pointed at local files instead of artifact asset URLs. Roboto and Roboto Mono were embedded locally; external requests were refused. Every page reported no page errors, and its document size equalled the board size, so nothing ran past the board. The prototype links between artboards were not exercised.

These are design references. They are not captures of the running application, not visual acceptance of the application page, not owner acceptance of the proposals, and not an entry in the accepted [UI baseline register](../../../../standards/ui-baselines.json). They were not captured from the claude.ai canvas itself, and a different font engine may render text slightly differently.
