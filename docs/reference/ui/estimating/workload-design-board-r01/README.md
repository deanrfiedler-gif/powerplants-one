# ES-01 Estimating intake and workload design board r01 — retained captures

These fourteen images retain the ES-01 design board for `/estimating` produced in the 24 September 2026 design session. The board applies the Powerplants One design system and the running shell to the native intake and workload register, and proposes a register with a persistent detail panel. It carries one user decision (use the Powerplants One design system) and proposals P1–P9 that are **not** accepted. The decision, proposals, open questions and build findings are in [the design board record](../../../../decisions/es01-design-board.md). Retain these bytes unchanged; a revised board receives a new revision folder.

Each image is one artboard captured at its exact board size in CSS pixels, at device scale 1. Names, references, dates and amounts are synthetic fixtures (`SYN` prefix). The running build's own captures remain in the [native workload evidence](../../../../testing/evidence/estimating-native-workload/README.md); none is embedded here.

## Capture method and limits

Captured on 24 September 2026 in headless Chromium 141.0.7390.37 through Playwright 1.56.1. The artboards are static HTML: each page was loaded from a local copy identical to the read-back file except that the logo pointed at the local asset and the Google Fonts stylesheet was replaced by a local `@font-face` for `Roboto-variable.ttf`. The Design runtime's `support.js` is not present locally, so each page ran without it; the static markup does not depend on it. The harness refused every non-local request, and none was attempted. No page reported an error, Roboto reported loaded, and each board's document and root size equalled its board size, so nothing ran past a board. The prototype links between artboards were not exercised.

axe-core 4.13.0 ran on every board with the WCAG 2.0 A/AA, 2.1 A/AA and 2.2 AA tags:

|---|---|
| 0 violations | V1–V3, R1–R4, X1–X5 |
| 1 violation, `color-contrast`, 1 node | D1, D2: the shell's `Ctrl K` hint (`#758091` on white, below 4.5:1), reproduced from `src/app/desktop-shell.css`. This is the shared-shell finding already recorded as B5 in the [ES-02 design board record](../../../../decisions/es02-design-board.md); the board does not restyle the shared shell |
| 61 contrast checks incomplete | R1: text beneath the modal scrim, which axe cannot resolve. The drawer's own text passed |
