# Reference cases and calibration proposals design r01 — retained captures

These fifteen images retain the Reference cases and calibration proposals design (ES-10) that Dean accepted on 30 October 2026. `/estimating/reference-cases` is not built; the design defines the build. They cover:
- the case register, including its last columns, and the Willowbank case detail;
- the comparison with 5 eligible jobs, and the comparison withheld at 3 of the proposed 5;
- the calibration proposal draft, its preview scenario and the independent review, with adoption unavailable;
- the estimator reference panel, drawn as an amendment over a copy of the ES-08 workbench;
- tablet 1024, phone 390 and 320, and states S1–S8.

The decisions, conformance declaration and departures D1–D13 are in [the design decision](../../../../decisions/reference-calibration-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Every value is synthetic.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own.
