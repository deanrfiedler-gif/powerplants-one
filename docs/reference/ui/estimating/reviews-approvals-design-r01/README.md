# Reviews & approvals design r01 — retained captures

These seven images retain the Reviews & approvals design that Dean accepted on 11 October 2026. The decisions, conformance declaration, departures and open questions are in [the design decision](../../../../decisions/estimate-reviews-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame, exported at scale 1 at its exact frame size. Every Font Awesome icon in the frame was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. Figures, names and references are synthetic fixtures. The images are design compositions, not captures of the application, which does not yet have this page.
