# Estimate detail design r01 — retained captures

These 21 images retain the Estimate detail and Create estimate design (`route:/estimating/estimates/[id]` and `route:/estimating/new`, within `scope:ES-01`) that Dean accepted on 30 October 2026. They cover:
- ten desktop frames at 1440, with full-length frames where the content needs it;
- the tablet record at 1024;
- the phone summary and read-only lines at 390 and 320;
- six states.

Images 01–07 and 11–19 belong to the Estimate detail page, and images 08–10, 20 and 21 to Create estimate.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/estimate-detail-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size, from the copies `2771:428051`–`2771:434352` on the Captures page.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The estimates, opportunities, references, people, dates and values are synthetic fixtures; they are not adopted operating rules and grant no authority. These are design compositions, not application captures, and they set no UI baseline.
