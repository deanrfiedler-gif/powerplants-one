# Report definitions design r01 — retained captures

These twenty-one images of twenty-one frames retain the Report definition, saved views and scheduled review design (`scope:RP-06`) that Dean accepted on 31 October 2026. They cover:
- the definitions register, definition record, version comparison, saved views, scheduled reviews, record a review, review history and export permissions on desktop at 1440, at the planned route `/reports/definitions`;
- the definition record on tablet at 1024;
- scheduled reviews and record a review on phones at 390 and 320;
- eight states.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/report-definitions-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The reports, definitions, versions, views, reviews, people, dates and export entries are synthetic fixtures as at Tue 13 Oct 2026 09:00 AEST; they are not adopted operating rules and grant no authority. An image that shows a definition as Adopted shows the story, not a real adoption: no report definition is adopted, no review is scheduled and no export permission is set by these images. They are design compositions, not captures of the application.
