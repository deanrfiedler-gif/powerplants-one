# Account development design r01 — retained captures

These twenty images retain the Account development design (CS-07) that Dean accepted on 31 October 2026. The route `/customers/[id]/development` is built with an earlier native treatment; this design has not been built. They cover:
- the register across customers (My accounts, By segment, No plan);
- the Hillview Growers development record, objective detail, Plan a visit and Record visit outcome;
- tablet 1024, the car-park phone views at 390 and 320, and eight states.

The decisions, conformance declaration and departures D1–D12 are in [the design decision](../../../../decisions/account-development-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Image 14 is a frame holding copies of the two phone state frames side by side.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own.

Everything shown is synthetic. Desktop frames are as at Tue 13 Oct 2026, 09:00 AEST; images 07 and 09 to 13 are as at Wed 21 Oct 2026, the day of the Q4 visit. These are design compositions, not application captures, and they set no UI baseline.
