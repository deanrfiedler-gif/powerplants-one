# Stakeholders design r01 — retained captures

These fifteen images retain the Stakeholders design (CS-03) that Dean accepted on 30 October 2026. The route `/customers/[id]/stakeholders` is built with an earlier native treatment; this design has not been built. They cover:
- People grouped by organisation, Site parties, the Relationship map with its list, Gaps and History;
- Change primary contact as a handover to People, and a person who has left;
- tablet 1024, phone 390 and 320, the phone Choose view sheet, eight phone states and one desktop state.

The decisions, conformance declaration and departures D1–D11 are in [the design decision](../../../../decisions/stakeholders-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Image 14 is a frame holding copies of the eight phone state frames side by side.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own.

Everything shown is synthetic, as at Tue 13 Oct 2026, 09:00. These are design compositions, not application captures, and they set no UI baseline.
