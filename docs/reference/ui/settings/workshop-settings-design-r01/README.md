# Workshop settings design r01 — retained captures

These twenty images retain the Workshop settings design (`scope:CX-02/settings`) that Dean accepted on 1 November 2026. They show a design, not an application page: `/admin/settings/workshop` is proposed and no route exists. They cover:
- the overview, the work instruction template, the test definitions register and the test record with its history;
- release rules and serial numbering in plain words;
- the Propose, Review and Publish dialogs;
- tablet 1024, phone 390 and 320 (overview and review sheet), and six desktop states.

The decisions, conformance declaration, D1–D12 and Q1–Q9 are in [the design decision](../../../../decisions/workshop-settings-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Every limit, person, date and record shown is synthetic; no limit is a real standard or a manufacturer's figure.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own.
