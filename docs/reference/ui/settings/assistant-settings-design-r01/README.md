# Assistant settings design r01 — retained captures

These sixteen images retain the Assistant settings design (AI-06) that Dean accepted on 30 October 2026, for the register destination `/assistant/settings`. They cover the overview at desktop 1440, tablet 1024, and phone 390 and 320; Provider and budget, the Switch provider dialog and the budget-used-up state; Capabilities and sources; Data handling; the evaluation runs and a synthetic example run; and Flagged answers with a flagged answer record on desktop and at phone 390 and 320.

Seven phone states are included. The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/assistant-settings-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Image 16 is a frame holding copies of the seven phone state frames side by side.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. Every figure, person, flagged answer and run is a synthetic fixture. Published data terms are shown as unverified. The example run is an illustration, not a result, and no frame names a pinned model. The images are design compositions, not captures of the application.
