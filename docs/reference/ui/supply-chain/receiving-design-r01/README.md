# Receiving design r01 — retained captures

These twenty-four images retain the Receiving design (SC-04) that Dean accepted on 31 October 2026. They show the design, not the native `/supply/receipts` page, which isn't changed. They cover:
- the register, grouped by disposition;
- the receipt record: Lines, Inspection, Quarantine, Affected demand and History;
- the Record receipt, Release from quarantine and Correct a receipt side forms;
- tablet 1024, phone 390 and 320 (list, record, count form), and eight phone states.

The decisions, conformance declaration and D1–D9 are in [the design decision](../../../../decisions/receiving-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own, from the [logo pack r01](../../ppo-logo-pack/README.md).
