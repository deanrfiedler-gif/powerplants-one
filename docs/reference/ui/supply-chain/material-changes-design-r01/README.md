# Material changes design r01 — retained captures

These twenty-one images retain the Material change impact design (SC-09) that Dean accepted on 31 October 2026. They show the design, not the native `/supply/changes` page, which isn't changed. They cover:
- the register, grouped by status;
- the change record: Summary at full length, Affected records, a receipt correction waiting on an owner, a shortfall with exact reductions, and a change resolved with holds;
- the Record follow-through side form;
- tablet 1024, phone 390 and 320 (my action, Acknowledge, acknowledged), and seven desktop states.

The decisions, conformance declaration and D1–D11 are in [the design decision](../../../../decisions/material-changes-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own, from the [logo pack r01](../../ppo-logo-pack/README.md).
