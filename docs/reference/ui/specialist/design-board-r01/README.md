## Capture method and limits

Captured on 23 September 2026 in headless Chromium through Playwright. The pages were served locally with the Design type's runtime, React and ReactDOM 18.3.1, and locally served Roboto and Roboto Mono. Every page reported no page errors, and its document size equalled the board size, so nothing ran past the board.

These are design references. They are not captures of the running application, not visual acceptance of the application pages, and not an entry in the accepted [UI baseline register](../../../../standards/ui-baselines.json). They were not captured from the claude.ai canvas itself, and fonts rendered by a different engine may differ slightly.
