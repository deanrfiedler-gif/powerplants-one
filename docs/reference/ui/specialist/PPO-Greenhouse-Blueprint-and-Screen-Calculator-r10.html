Method & limitations

Structure families. r10 supports four independent study models: Venlo dual-peak, Quonset circular-segment high tunnel, Gothic multi-span and Sawtooth multi-span. Switching structure family preserves the last geometry used for every family.

Project identity and comparison. Optional project metadata is carried into exports and drawing title blocks. Capture baseline stores the current common estimating metrics so another live configuration can be compared without implying an engineering preference or approval.

Readiness checks. The five-item review strip separates model validity, structural-grid conformity, screen-opening validity, roll-width fit and engineering-release status. Engineering release always remains “Not issued” in this study tool.

Venlo geometry. Roof rise = module width ÷ 4 × tan(roof pitch). Residual width modules preserve the selected slope but are custom study geometry.

Quonset geometry. The hoop is a circular segment defined by overall width, straight-side/spring height and ridge height. The model is limited to a minor circular segment.

Gothic geometry. Each span uses a symmetric pointed quadratic study curve. The selected equivalent roof-rise angle determines gutter-to-ridge rise; a fixed crown factor controls the pointed curvature so drawing, volume and roof-arc calculations share one consistent model. It is not a manufacturer tube-bending profile.

Sawtooth geometry. Each bay is a repeated single-slope roof rising from eave/gutter level to a high side. The high-level vertical step can contain a gross vent-opening study. Vent area is geometric gross opening only, not effective aerodynamic ventilation area.

Screen openings. Venlo, Gothic and Sawtooth use one horizontal screen opening basis per structural span/module. Quonset uses the horizontal circular-profile chord at the selected screen elevation. The entered allowance is subtracted once.

Partial modules/sections. Custom mode preserves exact overall length and any supported residual condition. Whole-grid mode never rounds dimensions; it blocks cut-study export when the selected longitudinal grid is not satisfied.

Screen length. Study length = actual longitudinal section × (1 + installation overlength). The setting is not treated as a universal shrinkage factor.

Procurement. Roll figures assume one panel across the roll. If usable roll width is unknown, fit is explicitly “not checked”.

Fabrication status. No supplier-specific product rules, hems, seams, overlaps, reinforcement, attachment allowances, parking clearances, multiple screen layers, structural loads or connection design are invented.
