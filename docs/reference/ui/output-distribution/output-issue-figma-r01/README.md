# Output, issue and distribution design r01 — retained captures

These twenty images retain the Output, issue and distribution design (DK-03, app label "Outputs") that Dean accepted on 15 October 2026. The decisions, conformance declaration, display rules and departures are in [the design decision](../../../../decisions/output-issue-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size; the states board is a Figma section, which exports with a 40 px margin. Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. Names, references, customers, sites, hashes, byte counts and dates are synthetic fixtures. The images are design compositions, not captures of the application, which has no output register page; `/documents/issues` is unbuilt.
