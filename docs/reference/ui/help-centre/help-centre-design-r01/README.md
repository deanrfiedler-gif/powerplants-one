# Help Centre design r01 — retained captures

These nineteen images retain the Help Centre and page guides design (DK-07) that Dean accepted on 1 November 2026. `/help` is not built; the design defines the build. They cover the guide panel, the Help Centre home, search, a journey, a task with its SOP, the reading view, the development draft section, no guide, coverage, gaps and guide review, at desktop 1440, tablet 1024 and phone 390 and 320, with ten state frames.

The decisions, conformance declaration and departures D1–D15 are in [the design decision](../../../../decisions/help-centre-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame, or a row of frames on a plain background, exported at scale 1 from copies on the Captures page (115:2) at y = 1,560,000. Those copies were deleted after export. The story is synthetic: no guide text, SOP, person or count is a real instruction or record. Coverage and chapter counts are synthetic, apart from the register's totals.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository.
