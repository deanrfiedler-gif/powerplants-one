# Customer messages design r01 — retained captures

These 28 images retain the Customer messages design (EC-04) that Dean accepted on 22 October 2026: the outbound queue for customer notices, at desktop 1440 × 900, tablet 1024 and phone 390 and 320. They cover the register, the exact message and Confirm and send, the delivery history, the M4 approval by a second person, the held, outcome-unknown and failed follow-ups, the class switches, the phone sheets, and seven states.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/customer-messages-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size. Image 16 is the full-length phone message; images 22–26 are the right-hand message card of a desktop frame in each state, and 27–28 the register content area.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo in the desktop rail is the company's own. The people, addresses (`*.example`), organisations and records are synthetic fixtures, and `customers@powerplants.example` is a placeholder for the shared mailbox. The images are design compositions, not captures of the application; every outcome shown is simulated.
