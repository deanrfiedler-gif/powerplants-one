# Calendar design r01 — retained captures

These eighteen images retain the Calendar design (EC-03) that Dean accepted on 19 October 2026. They cover one route, `/calendar` (the Sales rail's "Activities"): Week, Day with the meeting detail panel, Team availability, Plan follow-up and List on desktop 1440 × 900; Week on tablet 1024; Day at 390 and 320, List, the meeting sheet, Choose view and the full-screen Filter on phone; and six states.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/calendar-figma-design.md). The phone frames use the compact phone header of the Phone header amendment (`docs/decisions/phone-header-amendment.md`, draft PR #606). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The people, organisations, meetings, addresses and times are synthetic fixtures. The images are design compositions, not captures of the application.
