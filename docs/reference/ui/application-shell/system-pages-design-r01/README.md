# System pages design r01 — retained captures

These twenty-eight images retain the System pages design (`system:shell`, `route:/login`, `route:/`) that Dean accepted on 1 November 2026. The pages are not built to it. They cover sign-in and its outcomes, page unavailable, workspace access denied, error, could not start, the shared uncertain-outcome pattern, the offline banner and the existing synthetic markers. The [decision](../../../../decisions/system-pages-figma-design.md) records the acceptance, departures and answers.

They are copies of the accepted frames on the Figma "Captures (icon-free)" page from y = 1,460,000, exported at scale 1, with Font Awesome icons replaced by `Icon/placeholder`. Sign-in frames use the login page's local drawings, which are not Font Awesome. Images 10–14, 19–21 and 27 hold several frames on one sheet.

Request access (D4) and ideas I1–I3 are drawn on the page but are outside the accepted baseline, so they are not captured. Idea I4 appears as one labelled row in image 18. Image 25 is a composition, not a browser zoom test. Images 03 and 05 are byte-identical on purpose: today an expired attempt and an expired session show the same message, and image 22 shows the accepted wording for the attempt (D3). All people, references and operations are synthetic.
