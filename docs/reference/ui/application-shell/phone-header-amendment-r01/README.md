# Phone header amendment r01 — retained captures

These four images retain the Phone header amendment that Dean adopted on 19 October 2026 and accepted with the named Figma version "Phone header amendment — accepted", saved the same day: one compact 56 px header row on phone pages (rules P1–P9). The decision, the rules and how the library component and the accepted pages were brought into line are in [the design decision](../../../../decisions/phone-header-amendment.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size, from copies on the file's "Captures (icon-free)" page under the heading `1556:417691`. Images 03 and 04 are frames holding the section's contents at their positions. In the copies the compact header instances were detached, so later component edits cannot change them, and every Font Awesome icon (154) was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. Records, people and dates are synthetic fixtures. The images are design compositions, not captures of the application.
