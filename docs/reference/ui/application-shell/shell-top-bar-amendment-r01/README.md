# Shell top bar amendment r01 — retained captures

These six images retain the Shell top bar amendment that Dean accepted on 16 October 2026: the shorter breadcrumb (R1–R8) and the global search centred in the top bar (R9). The decisions, the rules and how the shared component, the accepted pages and the application were brought into line are in [the design decision](../../../../decisions/shell-top-bar-amendment.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size, from copies on the file's "Captures (icon-free)" page. Image 03 is a frame holding the R9 section's contents at their positions; its Shell / Top bar (proposed, centred search) component is shown as an instance. Every Font Awesome icon (247) was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. Records, people and dates are synthetic fixtures. The images are design compositions, not captures of the application.
