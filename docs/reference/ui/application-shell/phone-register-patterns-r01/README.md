# Phone register patterns amendment r01 — retained captures

These thirteen images retain the Phone register patterns amendment that Dean accepted on 1 November 2026. They show the design, not the application, which isn't changed. The rules, answers, conformance declaration and what remains open are in [the decision](../../../../decisions/phone-register-patterns-amendment.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma section or frame exported at scale 1. States are split into two images because the export caps at 4,096 px. Sections export with a 40 px margin.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The ticks inside selected checkboxes are icons, so they appear as squares here too. In capture 02 the new parts appear as instances of the page's components.

The copies are on "Captures (icon-free)" `115:2` under the heading "Phone register patterns amendment r01". The named Figma version had not been saved when these were made.
