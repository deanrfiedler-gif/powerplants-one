# Project financial performance design r01 — retained captures

These twenty-two images retain the Project financial performance design (FN-03) that Dean accepted on 19 October 2026. They cover `/finance/projects` (the Finance rail's "Project performance"), the proposed record at `/finance/projects/[id]` and the monthly review: ten desktop 1440 frames (two at full length), the tablet 1024 register, four phone frames at 390 and 320, and seven states.

The decisions, conformance declaration and departures are in [the design decision](../../../../decisions/project-financial-performance-figma-design.md). Retain these bytes unchanged; a revised design receives a new revision folder.

Each image is one Figma frame exported at scale 1 at its exact frame size.

Every Font Awesome icon was replaced by a plain placeholder square before export, as [ADR-0053](../../../../decisions/ADR-0053-figma-page-design.md) requires, so no Pro artwork is in this repository. The Powerplants logo is the company's own. The people, organisations, projects, amounts and dates are synthetic fixtures; no MYOB figure is shown. The images are design compositions, not captures of the application.
