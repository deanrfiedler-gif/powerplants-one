# ADR template

Copy this structure into a numbered ADR only when there is a concrete decision to assess. This template is not a recorded decision.

- Title and repository-local ADR identifier.
- Status: proposed, accepted, rejected or superseded.
- Decision owner and date/evidence of acceptance.
- Related requirement, D, IF, NFR and acceptance IDs.
- Context and constraints, including unresolved source facts.
- Options and relevant cost, maintenance, access and recovery trade-offs.
- Selected decision and rationale.
- Consequences, migration/compatibility effects and reversal path.
- Validation evidence and remaining questions.
