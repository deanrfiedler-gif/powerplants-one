# ADR-0016 — P10 synthetic Finance handoff

**Date:** 6 September 2026 · **State:** Implementation in progress · **Authority:** [P10 issue #45](https://github.com/deanrfiedler-gif/powerplants-one/issues/45). Private synthetic prototype only.

Keep the pinned modular monolith, PostgreSQL transactions, permanent identities, current scoped grants, original operation receipts and private write-once document adapter. Migration 0011 follows the accepted CRM 0010; no earlier migration, seed or issued byte changes.

Finance reads its own restricted projection of exact P09 report/review/entry and issued-byte evidence. The original field Draft flag is historical. Incomplete time/material declarations, missing original bytes, stale review and unsupported quantities block readiness. Attendance acceptance alone is insufficient. Owned partial work is explicit and requires a recorded Finance basis; it is never silently closed.

Existing ERP mappings prohibit Verified because live verification is not implemented. Preserve that guard. A separate immutable SyntheticVerified account context records the exact proposed mapping/version and independently defined fixture identity; this never upgrades a live mapping or asserts an MYOB action.

Use SyntheticManual by default. A bounded fixture simulator supports the maintained F-07 accepted-then-timeout obligation; it is local, never a configurable external endpoint. Approval, processor claim, observed outcome and reconciliation are distinct facts and capabilities. The original processing correlation/input hash survives retries. A possible effect requires lookup, not another target creation. Unknown, partial result and evidenced NotProcessed remain distinct. No operational tax, price, currency conversion, stock movement, payroll, billing threshold or accounting policy is inferred.

Revisions, reviews, source references, line quantities and target observations are immutable. Allocation holds consume billable and non-billable quantities alike. Returned retains holds until explicit revision/release; cancellation is allowed only before any possible effect. Source successors invalidate active readiness; possibly processed allocations remain held and require evidence-backed correction. Like-unit decimal quantities use exact integer scaling, not floating-point rounding. F-06 defines Labour only; original Travel/Break/Waiting/Other categories are blocked without reclassification until an explicit maintained treatment exists. The bounded first handoff dispositions each selected source quantity completely; split lines and shared target groups preserve independently checked conservation.

Review, processing and reconciliation demo identities have separate explicit Company grants. Systems and service ownership grant no Finance approval. Every read/command/file/receipt checks current scope before returning data. OUT-14 uses an exact reviewed source/template/audience snapshot, reserved preparation time, immutable stored bundle and separate actual issue event; storage recovery locates the original operation and never regenerates retained bytes.

Account runs retain independent F-01–F-05 observations, as-at, cutoff, pagination/count completeness, status/reversal lineage and separate unapplied cash. Partial/failed extraction cannot publish an account balance from visible rows; absent definitions remain Not defined. These are fictional fixture assertions, not operational D-017 closure.

Alternatives rejected: updating P07 originals destroys evidence; marking existing ERP mappings Verified invents live verification; automatic target replay duplicates effects; netting cash or inventing rates supplies unapproved policy; a second storage/workflow framework adds unnecessary infrastructure.

Primary technical references checked 6 September 2026: [PostgreSQL locking](https://www.postgresql.org/docs/16/explicit-locking.html), [Playwright PDF](https://playwright.dev/docs/api/class-page#page-pdf), [Next.js data security](https://nextjs.org/docs/app/guides/data-security). These establish mechanisms; PPO synthetic rules above remain bounded design decisions. Actual verification, limitations and publication belong to the P10 handover and external issue record. P11/P12 implementation, hosting and live integration remain outside this authority.

P11 amendment: [ADR-0018](ADR-0018-p11-travel-and-integrated-quality.md) supersedes only the Travel unsupported-treatment rule for the selected private synthetic journey, following Dean’s 7 September approval. All other P10 boundaries remain.
