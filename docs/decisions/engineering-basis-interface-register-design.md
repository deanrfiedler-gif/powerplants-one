## Architecture choice

Retain the repository's existing standalone HTML pattern: plain JavaScript, embedded CSS/font data and a deterministic Python assembler. This keeps the review artifact portable and separates the pure synthetic model from its UI. No framework, application dependency, database migration, provider or service is introduced. A static image would omit the stateful review/recovery journey; an immediate application integration would require unresolved authority, source and receiving contracts. The authorised plan selected the standalone approach before this build.

SHA-256 identities cover actual serialized basis, source and policy content. They support exact comparisons; they do not establish a trusted signature. Browser storage guards preserve local pending input and demonstrate expected versions/original-operation replay; they do not replace server transactions or cross-tab atomicity.

## Delivered controls and limits

The model prevents cross-site records, orphaned scope, stale saves, changed-content operation replay, self-review, incomplete positive review and repeated receiving effects. Source adoption reopens directly and indirectly dependent agreements/checks. Corrections use a successor; earlier submissions, decisions, source content and receiving payloads remain retained. A missing authority-policy example has no permissive reviewer fallback.

Normal review and pending-input exports sanitize the selected package's restricted source. The role selector is a workflow demonstration. The original-state recovery export deliberately retains original bytes; it and the HTML source are available to the file holder. No security claim follows from these local previews.

The artifact is not fully verified against the original plan's native-browser gate: the review browser blocked the local URL under its URL policy. No workaround was attempted. All 38 model and 22 DOM groups passed; native rendering, screenshots, real keyboard/assistive-technology use, browser download behavior, 320 px and zoom checks remain pending. Unit conversion, native calculations, automated impact completeness and historical print selection are not implemented. See the report's exact plan-to-delivery mapping.
