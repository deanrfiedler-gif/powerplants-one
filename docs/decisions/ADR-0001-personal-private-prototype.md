# ADR-0001 — Personal private prototype repository

**Status:** Accepted for current prototype ownership, from explicit user direction.

**Decision owner:** Dean Fiedler. **Related master decisions:** D-003, D-029; company sponsorship/delegation D-001/D-002 remain separate.

## Context

Master Blueprint v02 proposed a future company-controlled GitHub organisation. Dean subsequently clarified that he will create his own private prototype, created `deanrfiedler-gif/powerplants-one`, and authorised preparation of the repository foundation.

## Decision

Use the existing personal account and private repository for prototype documents and future authorised development. Retain the working name Powerplants One and repository slug. Use one repository initially. Keep the issued master/audit unchanged and record current decisions alongside them.

## Consequences

The blueprint's proposed company organisation is not a prerequisite for current prototype documentation work. The formal programme reference, future ownership arrangements, licensing, paid-plan features and production support remain unresolved. SOL008 continues to identify the separate Smartsheet delivery-system work.

This decision does not select an application stack, approve production integration, authorise ERP writes, retire Pipedrive/Smartsheet or approve any company organisation chart. Review ownership and access before wider company use or a transfer.

## Evidence

Source: user statements in the originating conversation, followed by read-only confirmation of repository owner, private visibility, default `main` branch and initial README. This ADR records that scope; it does not infer a corporate mandate.
