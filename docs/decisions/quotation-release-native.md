## Bounded synthetic policy

`SYN-ES05-01` uses the local estimate owner as preparer and two explicitly named fictional local identities, Quotation approver and Quotation issuer. Each receives only the current Company A reads and its own explicit command duties. The owner, source author and preparer cannot approve; neither preparer nor approver can issue. These fixtures have no hosted invitation, operational delegation or live distribution capability.

`PPO-SYN-RELEASE-r01` and `PPO-SYN-NONOPERATIVE-TERMS-r01` state that the document has no commercial validity and authorises no work or payment. Approved operative terms, financial exceptions and a real validity period remain Not configured. Existing E1 AUD excluding-tax arithmetic and include/print choices are retained without new money calculations. The initial manual journey has one exact estimate option; optional commercial packages are unavailable until their pricing/selection contract is adopted.

Preparation creates a successor revision in the existing quotation, retaining exact estimate/scope, choice, review-decision, customer/contact/site-version, policy and template bindings. It never changes an earlier Draft. Approval binds the actual retained HTML/PDF manifest. Issue rechecks current applicability and authority, stores that exact approved manifest, and explicitly names the preceding issue. Earlier issue bytes stay retrievable. A new preparation inherits no approval.

Distribution is an attributable **simulated** outcome recorded against an exact issue. No send button, email, customer endpoint or live provider is connected. Preparation, approval, issue, simulated delivery and customer response remain separate facts. ES-06 will record exact synthetic responses; ES-07 will independently receive any downstream handover. Neither is implied here.
