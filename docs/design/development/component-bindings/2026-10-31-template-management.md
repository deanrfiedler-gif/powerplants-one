# Template management consumer bindings

Owner: Dean Fiedler. Source: [accepted DK-06 contract](../pages/scope-dk-06.md). Implementation and independent review remain in progress; no acceptance or review fingerprint is claimed.

## buttons

Commands are disabled while busy or uncertain. Confirm original action retains the original path, operation ID, body, exact revision and fingerprints. Site assignment binds the displayed policy and server-time interval.

## register-table

Definitions/proposals use identity-order native pages. Load more re-reads the visible window, preserves rows while pending, focuses newly added evidence, and clears all rows after an unconfirmed read. Snapshot focus returns to its checkbox on Escape.

## fields

Proposal drawers preserve the exact base and immutable review scope on revision. Ordered fields use permitted native binding choices. Phone fields stack at 320 px; a stale decision retains typed values.

## tabs

Record tab selection survives refresh. Publication readiness is publisher-only; retained publication evidence is available when its native read permits it. A seeded definition has no Publication tab.

## menu

The existing secondary menu starts collapsed for exact records. Phone family and company/site filters open from the single compact header, replacing toolbar rows; no global totals or combined-family catalogue is implied.

## dialog

Review, Publish and Assign use are separate centered WorklistPanel dialogs. Validation and stale refusals retain the input. Uncertain outcomes lock editing and closing until the original operation is reconciled.

## drawer

The scoped consumer stylesheet binds WorklistPanel to a right-side drawer and centered decisions, with a fixed header, scrolling body, 44 px close target and full-screen phone treatment. New and Revise proposals reuse the side drawer with exact base/body evidence. Snapshot is a non-modal complementary region with focus entry, Escape and return to its trigger.

## application-shell

One SecondaryMenuFrame owns the phone header. Lists provide Filter and, when permitted, New proposal; pull-down re-reads current evidence. Phone records hide the shell tab bar and keep their main action at the bottom.

## read-state

Loading, permitted empty, denied/unavailable, expired continuation and stale command states remain separate. Current-authority failures clear displayed evidence; no sample values are substituted.
