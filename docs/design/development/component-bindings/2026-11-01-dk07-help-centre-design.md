## Application shell and global navigation

The accepted [DK-07 design](../../../decisions/help-centre-figma-design.md) keeps the shell's information icon as the one entry to page help, and adds a non-modal guide panel over the page. Tablet uses the same overlay. Phones open a full-screen reader from Page guide in the menu (P4), using the compact record header. Help Centre is reached from More, the panel footer and the phone menu, never from a second top bar button. Nothing is built; this note records the design's use of the shell. Section 6 of the decision lists where the design differs from the [guidance contract](../systems/guidance.md).

## House register table

The coverage view and gaps worklist are a grid register grouped by module, using Grid / Header cell, Cell, Checkbox cell, Row actions and Group band. Status is always in words, and stale carries a word and an icon. Nothing is built.
