## Status

PJ-01 uses the shared Tag inside a new Figma part, Initiation / Review status, on each row of the receiving review. It adds a border and a chevron, so the status is also the control that changes it. Status is always in words. Choosing Needs clarification opens the Raise a question panel with the item filled in; Not applicable asks for a short reason. The part is in the [accepted PJ-01 design](../../../decisions/project-initiation-figma-design.md) and is not built.
