## Native behaviour

The entry is **Estimating → Priva Fertigation Configurator**, with a contextual entry from saved Discovery. Create a scope against an authorised exact alternative and revision. Production context is neutral and explicit; berries, nursery, medicinal cannabis and other tags do not choose arithmetic or grant permission. Canonical Facility and Asset identities remain owned by their existing services.

Irrigation valves and mainline/master valves have prominent add/edit registers, stable identities, phase, source/circuit, allocations and manual/external/controller assignments. Editors apply changes to an in-memory proposal. **Save revision** persists the full validated graph atomically with its calculation, input hash, source fingerprint and immutable content hash. History opens the exact saved revision; copy and restore create successors without rewriting it. Permission, stale source, version and original-operation recovery checks apply at service and direct HTTP boundaries.

The first supported consumption/timing/storage model is a bounded sequential single-pass drip circuit. Measured/design flow remains usable for non-container scope without fabricated population. Per-container demand, allocation delivery, recirculation and unsupported application methods retain explicit unknown, not-applicable or unsupported states. Commercial berries is the first arithmetic and application reference journey. Candidate families retain exact configuration evidence and unresolved conflicts; manufacturer suitability is never inferred from a family label or a hypothetical envelope.

Operating scenario comparison evaluates two plans over the same physical proposal without changing the selected saved scenario or combining their duties. Valve registers also filter by represented area. Candidate detail exposes each required quantity, entered limit, applicability, source and next action; no entered range becomes manufacturer confirmation.

Review records bind an authenticated actor, exact saved revision, calculation edition, source dependencies and unresolved purpose/conditions. Engineering approval is **not configured**. A receiving preview shows the exact prepared and current source fingerprints, previous accepted quantities and the proposed change before acceptance. Prepared/accepted manual scoping notes are distinct from adoption for costing; existing selected Complete Discovery and pricing gates remain authoritative. No SKU, price, tax, margin or estimate line is generated automatically.

Original PNG evidence is validated and bounded to 4 MiB. [Abandoned local upload maintenance](priva-fertigation-orphan-cleanup.md) audits permanently closed failed operations and permits removal of one exact unreferenced orphan after a retention period; committed preparations and historical bytes remain retained. Preparing bytes does not alter a saved scope. Add the prepared hash-bound reference to the draft and save a successor to include it in the scope/review basis. This is not a general document-upload or malware-scanning capability. Original document objects and retained HTML/PDF are privately downloaded only after current authorisation of the bound historical revision. Reports project the audience allowlist before serialisation; customer output excludes internal free text and restricted attachment metadata. All reports are synthetic drafts, not construction or commissioning releases.

Native JSON exports preserve typed scope and calculation provenance (8 MiB portable/import envelope; 2 MiB editable graph), with explicit exclusions for original file bytes and transferable approval. Import previews remap scope-owned identities and require an explicit authorised saved source; incomplete legacy mappings and file reattachment requirements are held. Fully representable standalone schema-1/2 files can be previewed and confirmed as new drafts with unverified provenance. Real unmapped history, file bytes and unsupported semantics remain held. CSV preview/import uses the exact 17-column valve-register export contract; missing related register facts stay explicit unknown placeholders. It is a valve-register projection, not a lossless portable scope. No executable attachment, arbitrary remote document fetch or customer/supplier transmission is introduced.
