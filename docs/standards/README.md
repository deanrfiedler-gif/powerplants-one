# Project standards and working instructions

Powerplants One / PPO uses an independently adopted naming system. The other project's STD-001 is not an authority for this repository.

| Item | Purpose |
|---|---|
| [PPO-STD-001](naming-conventions.md) | Current adopted naming standard; r03 records adoption of the accepted r02 scheme |
| [Accepted r02](../reference/baselines/PPO-STD-001-naming-conventions-r02.md) | Exact user-adopted source, hash-protected |
| [ADR-0005](../decisions/ADR-0005-project-naming-adoption.md) | Adoption, supersession and scope |
| [Implementation record](naming-adoption.md) | Old/new paths, design-contract changes and assurance |
| [Document register](document-register.csv) | Identified documents and reserved blueprint paths |
| [Exceptions register](naming-exceptions.csv) | Explicit standing exceptions and compatibility requirements |
| [ChatGPT project instructions](chatgpt-project-instructions.md) | Complete copy-ready text for the dedicated project |

The register covers formally identified project documents; descriptive contracts and ordinary support files retain their existing path identities. Planned blueprint rows reserve names without claiming the documents exist. Runtime implementation follows the current P01–P12 plan.
