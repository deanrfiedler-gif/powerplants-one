# Powerplants UI assets

The [complete supplied logo](powerplants-logo-green-white.png) is copied byte-for-byte from `GEN_LGO_PPALogoPrimaryTransparent_v01_ISS.png`; the reattached `(1)` copy matched. Do not crop, recolour, separate the symbol/wordmark or distort it. Use the authorised private-design treatment and clear-space rules in the [shared UI specification](../ui-style-specification.md).

The [mockup manifest](../../blueprints/crm-ui-mockups/manifest.json) records provenance and hashes. The repository does not redistribute the full company brand PDF or operational screenshots.

The standalone design preview embeds Roboto font subsets extracted from the supplied PDF, retaining the Roboto Project Authors copyright. The upstream [Roboto 3 Classic project](https://github.com/googlefonts/roboto-3-classic) provides its [OFL 1.1 text](roboto-ofl.txt). These subsets support the illustrated content; the application should use a verified complete font distribution for supported languages.

The preview also embeds the 16 used icon geometries from Lucide 1.17.0. Its [ISC and inherited MIT notices](lucide-license.txt) are preserved from the [upstream version](https://github.com/lucide-icons/lucide/blob/1.17.0/LICENSE), and both font/icon notices are embedded in the standalone HTML. Icons are functional UI artwork, not supplied Powerplants category marks. No new runtime package is added to the application.

I2 serves the complete upstream [Roboto 3.015 variable normal font](../../../public/brand/Roboto-variable.ttf) as a same-origin static asset, with its [OFL licence](../../../public/brand/Roboto-OFL.txt). Source: google/fonts commit `6183fc0d26361f6ddfd6f6b7a736e1467c6d8a43`, `ofl/roboto/Roboto[wdth,wght].ttf`, Git blob `5522a368d9072fd88c299916e61fcff369949061`. The unchanged 488,584 bytes have SHA-256 `d7598e12c5dbef095ff8272cfc55da0250bd07fbdecbac8a530b9b277872a134`. Font inspection finds 927 Unicode codepoints, weight 100–900 and width 75–100 (normal default 100). The application uses normal width with Roboto/Verdana/sans-serif fallbacks; this is not a claim of universal language coverage. The complete font replaces reliance on the design's illustrated-content subsets without adding a runtime package, remote font request or icon dependency. Browser checks verify the loaded face and original response hash; exact executed results belong to the I2 handover/publication.
