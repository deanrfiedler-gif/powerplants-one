A second, independent pass of the [cross-file Figma alignment audit](../decisions/figma-cross-file-alignment-audit.md) (PPO-FIGMA-ALIGNMENT-AUDIT) is recorded, so that the per-file alignment batches rest on evidence with node IDs and on far fewer unchecked cells. Dean asked a new session to run the same audit brief on Fri 13 Nov 2026 (his local date). The first pass was open as pull request #920, so this pass amended the same record in place instead of adding a competing one; its section is at the end of the record and the first pass's text is unchanged apart from the status line and a pointer. The pass re-extracted all 13 linked module files and the accepted Shell, read-only: 2,724 sheets on 159 scope pages, in 160 Figma calls. Of the 77 first-pass findings, 73 are confirmed (four of them wider than reported), one has changed because the Shell file gained an `action/primary` colour since, one was corrected in its file since, and two were not re-tested. The pass adds 88 findings, for 162 in all: 14 Blocker, 36 Major, 97 Minor and 15 Polish. The largest additions are cross-file facts (the same reference naming a different customer, amount, revision or date in different files), 146 date strings in the accepted Sales file whose weekday does not match the 2026 calendar, a customer portal sheet whose quotation reference contains "PPO", three colour variables that differ between files, 160 state words whose chip tone differs between files, and reference families that carry two kinds. Of the 559 matrix cells for the linked files, 174 are Pass, 246 Fail, 37 Not applicable and 102 Not checked, against 366 Not checked in the first pass. Nine new questions for Dean (AC-21 to AC-29) join the first pass's twenty. No design is changed and nothing is accepted.

Checked: every finding carries the rule, the expected and found values, the fix owner and, where the text sits on a sheet, the sheet's node ID read from the file; each first-pass finding was re-tested against the fresh extraction; `python3 scripts/build_status.py --check` and `python3 scripts/check_foundation.py` pass; only the audit record and this fragment change beyond the two first-pass files this pull request carries. Not done: Addenda A1, A2 and A3 were not supplied, so the fact ledger is a reconstruction from the brief, the records and the files, and it cannot catch a fact that every file states the same wrong way; "PPO - Assistant, Knowledge and Help" and "PPO - Products" have no link and are not checked; "PPO - Library" was read through its records only; no screenshot was taken, so clipping, truncation and overlap inside a sheet are not checked; seven checks that need rendered sheets or a rule-by-rule reading stay Not checked; the chip-tone and after-09:00 findings rest on heuristics and are marked as such. The per-file alignment briefs, the findings and matrix CSVs, the fact ledger difference and the questions file are in the session's scratch files and were sent to Dean; they are not committed. No Figma file, application code, route, migration, permission, design register or other record is changed, and all 78 parent requirement IDs remain. Every record, person, value and date in the files is synthetic.
