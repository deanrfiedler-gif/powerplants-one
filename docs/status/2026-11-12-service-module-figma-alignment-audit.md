date: 2026-11-12

Dean asked for the Figma file of the Service module UI to be audited, so the proposal can be aligned with the accepted Shell, the Library and the other module files before he reviews and accepts it. The cross-file alignment audit was run read-only over "PPO - Service module (proposal)": all 17 scope pages and 288 sheets were checked. The checks compared the file against the accepted Shell at its named version of 10 November 2026, the Library's component and variable inventories, the file's own record and the facts and handovers in the other module records. The [audit record](../decisions/service-module-figma-alignment-audit.md) (PPO-SERVICE-FIGMA-ALIGNMENT-AUDIT) lists 43 findings: 1 Blocker, 22 Major, 17 Minor and 3 Polish. The Blocker is the scheduling, preparation and numbering policy editors, which both Service and Settings draw with different versions. The Majors are mostly cross-file facts and handovers that drifted (the portal release and response route, parts readiness, SYN-RPT-000039, the commissioning handover, Casey Ward's morning, the M-4 motor serial, Block C dates), shared-convention breaches (single-digit revisions, gendered pronouns, chip tones, off-scale text sizes, the green focus ring, 38 px phone tabs), the right strip on settings sheets and redrawn banners. The record also holds 13 questions for Dean and a paste-ready alignment batch for the file's next build session. Nothing in any Figma file was changed and nothing is accepted. The file links are not recorded (ADR-0050, ADR-0053).

Checked: 288 of 288 recorded node IDs resolve with matching codes and sizes. Every page's structure, grid and labels; the shell instances against the accepted components; the docked and flyout menus against the accepted workspace menus page; chip tones; type sizes; unbound fills; and ten contrast pairs from the file's variables (lowest text 5.21:1, UI edge 3.32:1) were all read from the file. Two sheets were rendered to confirm findings. Repository checks for this change: `python3 scripts/build_status.py --check` and `python3 scripts/check_foundation.py`. Not checked: Addendum A3 was not available (its facts were reconstructed from other records' citations); register footers and cell wrapping; the other module files' Figma pages (read through their records); keyboard, screen reader, zoom and device reviews. Every record, person, value and date shown is synthetic.
