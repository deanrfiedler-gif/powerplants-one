title: Customers, sites and equipment Figma file audited for alignment
date: 2026-11-13

At Dean's request the private Figma file "PPO - Customers, Sites & Equipment module" was audited, read-only, against the accepted Shell at its latest named version, the record header and reference addenda, Addendum A3 as the module records cite it, the PPO - Library and the other module records. The [audit record](../decisions/shared-records-figma-alignment-audit.md) (PPO-SHARED-RECORDS-FIGMA-ALIGNMENT-AUDIT) lists 24 findings: no Blocker, 10 Major, 9 Minor and 5 Polish. The file is structurally sound: all 200 sheets match the proposal record's node IDs, sit in their sections with one label each, are built from shell instances, bind every colour to the PPO colour variables and use Roboto only, and the contrast proof recomputes exactly. The Majors are the record totals on the proposed Shared records docked menu's views, phone record sheets without the A1 phone header and sticky bar, Stakeholders sheets without the record header, single-digit revisions, chip tones that differ from the file's own word-family sheet, the focus ring colour, four panel widths, and three facts that differ from the Service file or A3 (the expired test instrument, the motor M-2 replacement time and the Mallee Fresh site zone). Ten questions, one of them the authority conflict between the Shell's 432 px panel and the Library's drawer widths, wait for Dean, and an alignment batch is ready for the file's next build session.

Checked: about twenty scripted reads of the module, Shell and Library files, with rule checks run over every visible text on every sheet; node IDs compared with the record by script; nine contrast pairs recomputed; cross-file facts compared with the Sales, Service, Supply, Engineering and Settings records. Not checked: renders of three findings (marked plausible) after the Figma connection dropped several times; the Products, Customer portal, My Work and Settings files themselves. `python3 scripts/build_status.py --check` and `python3 scripts/check_foundation.py` were run for this change. No Figma file, application code, route, migration, permission, register or other record was changed, and nothing is accepted. Every record, person, value and date in the file is synthetic.
