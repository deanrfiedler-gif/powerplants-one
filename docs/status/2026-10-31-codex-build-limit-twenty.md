Dean raised the limit on Codex builds in progress from three to twenty on 31 October 2026. Earlier that day he had approved ten in a Codex chat, and six Codex pull requests had implementation pushed while `CONTRIBUTING.md` still said three. [CONTRIBUTING.md — Working in parallel](../../CONTRIBUTING.md#working-in-parallel) now states the new number, and the rule that Codex finishes an implemented build before starting another applies only at the limit.

What remains open: this pull request changes `CONTRIBUTING.md`, so under the autonomous agent protocol Dean merges it. It also changes an owner decision record, so it needs a second-model review first. The earlier evidence about conflicts and failing checks has not been retested at twenty.

No application code changed.
