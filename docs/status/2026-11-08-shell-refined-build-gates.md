---
title: Refined shell gains a page-header stage and a whole-shell gate
date: 2026-11-08
---

Dean decided on 8 November 2026, in a [DEAN] comment on [PR #874](https://github.com/deanrfiedler-gif/powerplants-one/pull/874#issuecomment-6728218179), that the refined shell must match the accepted Figma design exactly. S1's separate breadcrumb band is accepted only as a temporary bridge for identities that opt in. A page-header stage, designed first by Claude in the accepted shell file and accepted by Dean under a new named version, moves the breadcrumb and page hierarchy into a shared page header and removes the band. The refined shell becomes the default only after a whole-shell comparison against the named version, with every difference fixed or accepted by Dean. The [decision record](../decisions/shell-refined-build-gates.md) holds the rules. No application code changes.
