Dean accepted the Figma design for Changes and follow-up, scope PL-04: the queues at `/schedule/changes` and Policy impact at `/schedule/policy-impact`. - **Queues:** five side-menu views with counts, a Changes grid, and the PL-02 large snapshot showing the booking now beside what a change sets in motion: customer contact, job pack re-acknowledgement, site readiness and dispatch holds.
- **Decisions:** a stale request names what changed; a reason is still required; Cancel request moves into the request card's "…" menu; after an accepted move, "Record customer contact" is the primary action.
- **Policy impact:** a Review / comparison page in the same workspace.
- The top bar carries the proposed Conversations action; that shell amendment is still a separate, open record.

The File index row and page header were updated, and the copied links to Field team frames were removed; there is no PL-04 prototype flow. Nothing is built; the page design register notes for PL-04 gain "Accepted design" paragraphs. No code, route, migration, permission, capability or parent ID changes.
