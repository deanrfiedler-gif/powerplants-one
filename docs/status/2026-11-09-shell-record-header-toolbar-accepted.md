title: Shell record header toolbar accepted
date: 2026-11-09
---

Dean asked, from a screenshot of a quotation record header, whether its elements should be added to the module UI pages. Claude recommended one shared record header for every record page in every module and drew it in the private Figma file "PPO - Shell (accepted)" as a proposal: breadcrumb, one-row title with the state chip and a favourite star, a one-line sub-line, and a toolbar with previous and next within the register view, a labelled Actions menu, an Outputs menu and one state-driven primary action, with six state variants, a phone variant and an in-context quotation record sheet. Dean accepted it the same day ("Accept the record header toolbar as drawn"). The [shell decision record](../decisions/shell-refined-concept-design.md#10-record-header-toolbar--9-november-2026) gains section 10 with the node IDs, what was adopted and not adopted from the screenshot (no record-level Undo, no New button, no first or last record jump, no desktop back arrow; "Reports" named Outputs; "Issue & send" only at Approved · not issued for the issuer), and the [shell rules export](../design/development/systems/shell-refined-concept-rules.md#rules-r1r125) gains rules R116–R125. On acceptance the component set and the phone component moved into the file's accepted Components section with their node IDs unchanged. The Sales file adopts the header in a follow-up batch; the Estimating, Projects and Supply module files use it from the start. The file's link and key are not recorded (ADR-0050, ADR-0053).

Checked: every frame rendered and inspected; the page's top-level nodes do not overlap and every section contains its children; the Components section was extended to hold the moved components below its lowest earlier component; the page's references use the short form of the readable reference namespaces decision. Repository checks run for this change: `python3 scripts/build_status.py --check` and `python3 scripts/check_foundation.py`. Not done: a new named version of the shell file (Dean's to save; builds cite "Shell refined concept — accepted" for the shell and section 10 for the toolbar until then), the Sales adoption batch, any application code. Every record shown is synthetic.
