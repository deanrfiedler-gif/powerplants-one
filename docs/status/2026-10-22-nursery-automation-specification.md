Dean requested the [Nursery Automation specification](../blueprints/nursery-automation-configurator.md) and [equipment-data template](../templates/nursery-automation/README.md), starting with Javo potting lines. During preparation he directed alignment with the parallel estimating plan's adopted O1–O15 and DP1–DP8. The package covers equipment/scenarios/interfaces, separate labour facts, reusable delivery profiles, activity coverage and quotation content; CPQ remains the shared effort/pricing engine. The private plan link and questionnaire bytes are not published.

The detailed design and operating data remain proposed/unreviewed. The template contains blank entry fields and synthetic guidance examples, not approved Javo ratings or productivity standards. The [working design](../design/development/nursery-automation.md) records missing visuals and the [acceptance catalogue](../testing/nursery-automation-acceptance.md) contains 23 proposed tests, not executed application proof. Foundation, naming and design-register checks pass. All nine workbook sheets were rendered and inspected; independent file checks confirm 151 fields match the dictionary, 453 input cells remain blank and 176 dropdown cells retain their choices. Native Excel interaction is untested. No application, schema, shared contract, permission, route, integration or deployment change is included.
