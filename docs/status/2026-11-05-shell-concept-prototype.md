date: 2026-11-05

Dean requested refinement of the private shell concept after its audit: retain the navy rail, grouped flyout, command palette and snapshot; resolve snapshot scrolling, preview versus bulk selection, responsive layout and save/recovery states; build a clickable Sales and Service or Engineering trial. This Codex session owns `codex/shell-concept-prototype-record`.

The private Figma trial now contains 50 connected screens covering Sales and Service readiness, explicit authorisation and a Schedule handover. Snapshot scrolling, preview versus checked selection, responsive panel rules and save/recovery states are drawn and connected. Structural inspection found 427 destination actions and no unreachable trial screen or dangling destination. Representative player clicks and visual inspection are recorded separately from that graph proof.

The [decision record](../decisions/shell-concept-prototype.md), [working shell reference](../design/development/systems/shell.md) and [component consumer note](../design/development/component-bindings/2026-11-05-shell-concept-prototype.md) identify exact source nodes, proposed departures and limits. This is design delivery, not adoption of a replacement application shell. Application behaviour, operational authority, owner acceptance, physical devices, screen readers and real browser zoom remain separate. All existing scope and parent requirement IDs remain unchanged; no route, migration, capability, deployment or production transaction is added.
