## Purpose and outcome {#purpose}

Import a synthetic PPO workbook into one exact selected option and Complete discovery revision. Review evidence and save one immutable estimate version. Re-import, reviewed-source pricing and Draft preparation are separate commands.

## Before you start {#before}

Open Import Excel estimate from the Wizard Review Actions when no estimate exists, or an Excel action from an imported estimate. An exact Draft workspace, selected Active option, Complete discovery and Site are required. Estimating read/edit and ownership apply; Draft preparation additionally requires quotation prepare/read.

Use only a synthetic macro-free .xlsx within 5 MiB and the current PPO named-table contract. Recalculate and save in Excel. No operational departmental workbook has been supplied or verified.

## Quick start {#quick-start}

Choose workbook, then Validate workbook. Review errors, warnings, every line and reconciliation. Correct errors in Excel and upload again. Continue to confirm, give all four declarations and a reason, then save. Open saved result and verify the exact receipt/version.

## Understand this page {#page-tour}

The Wizard context and four step cards stay above the scrolling review. Desktop has an Import summary; Summary opens it on narrower screens. The action bar keeps Previous and the current action. Findings name their sheet, table, row and field.

## Information you need {#information}

Keep exact native reference IDs in the workbook. Unknown values are not zero. Original cells, cached formula evidence, section membership, source dates, independent include/print proposals and totals remain inspectable. Workbook reviewer declarations are source evidence, not authenticated PPO approval.

## Complete the main task {#tasks}

Revised workbook: validate, inspect changes and source-binding disposition, explicitly Keep or Remove every omitted line, then confirm replacements and the four source declarations.

Pricing: search permitted Cost Sources, select exact reviewed revisions for saved lines and a pricing date. Optionally enter authored AUD freight/duty charges with evidence and exact Product targets. Review workbook/current/proposed prices, tiers, recorded FX and every allocation before saving. Sell remains unchanged.

Draft: give separate include and print choices for kept lines without a current workbook proposal. Review the native reconciliation and customer-safe preview, confirm customer wording, choices and reconciliation, then prepare the Draft.

## Completion and handover {#completion}

A receipt proves command acceptance. Open its exact estimate version. A saved Draft is not a rendered PDF, issued quotation, customer delivery or commercial approval. Retained original downloads verify bytes; source_retained alone is not an availability probe.

## Statuses, warnings and save state {#states}

Blocked means workbook errors prevent the whole save. Ready for review means automated checks passed, not approval. A changed basis requires a fresh review; refused access clears protected data. Historical versions are readable but cannot be used as current pricing/Draft targets.

## Worked examples {#examples}

The browser proof creates its own synthetic workspace and native-bound workbook, corrects a missing unit cost, imports a revision with an omitted line kept, prices a selected line and explicitly decides the kept line’s quotation flags. These are proof fixtures, not departmental operating data.

## Troubleshooting {#recovery}

If the save outcome is uncertain, use Check original outcome or Retry exact original. The same-tab journal keeps the original operation identity and intent; it does not invent a replacement. A missing receipt is inconclusive. Do not clear browser recovery data to force a second save.

The browser must store the pending intent before sending. If tab storage is unavailable or full, no command is sent; keep the original workbook and resolve storage first. Large files can hit the browser’s quota below the parser’s 5 MiB limit.

## Mobile, keyboard and offline use {#mobile}

At 390/320 px use Show all lines to reach the complete scrollable grid. Summary opens a keyboard-dismissable dialog and returns focus. Controls retain labels and readable input text. This is an online workflow; the recovery journal is not an offline queue.
